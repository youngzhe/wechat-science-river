# 科学长河：发现之旅

第一章《白光里的秘密》的原生微信小程序 2.5D 可玩原型。

## 导入运行

1. 安装微信开发者工具。
2. 选择“导入项目”，项目目录选择本仓库根目录（此处的 `project.config.json` 会将小程序根目录指向 `miniprogram/`）。
3. AppID 当前使用开发者工具游客模式占位；需要真实账号、真机预览或发布时，请在工具里换成自己的小程序 AppID。
4. 编译后从“开始探索”进入书房。项目不依赖 npm 包或服务器。

## 建议试玩顺序

1. 在书房检查窗缝、棱镜、白屏和手稿，选一个初始想法（也可以选暂时不确定）。
2. 实验台放入第一块棱镜，观察并记录 E1。
3. 切换到“单色再试”，选红色、调窄缝、放入第二块棱镜，记录 E2；再换蓝色记录 E3。
4. 切换“合回白光”，放入透镜并把白屏移到约 0.62 的位置，记录 E4。移动白屏可对照光斑变化。
5. 在笔记先选一个迁移预测，再去验证另一种色带；关联 E2/E3 到当前解释后即可结案。
6. 卡住时点“找小助手”逐层看提示。L4 会代为摆好当前卡点的步骤，观察和记录仍由玩家触发。

## 已实现范围

- 章节入口与本地继续进度。
- 书房物件调查、初始猜想、原创书房与小墨团素材。
- 小墨团共用形象组件：主页、书房对白/开场卡、结尾档案统一使用暖炭灰身体与高对比青绿披风的 3D 风格透明图；保留不对称可爱轮廓，点按短暂切换姿态，图片加载失败回退原插画。
- 实验台：棱镜、窄缝、选色、第二棱镜、透镜、白屏位置和遮挡操作；结果由独立教学光学模型计算。
- E1-E4 观察快照、解释关联、四层分级提示、猜想修正、迁移预测与结案档案。
- 本地版本化存档，快照采用深复制；所有关键操作有按钮方式，暂不要求精确拖动。
- 2.5D 视觉：书房空间底图、轻视差/浮动、尘埃微动、实验光路发光动画和场景推近过渡。
